<h2>一、先定接入方式再买设备</h2>
<p>同样是住宅线路，桥接和路由两种模式需要的设备不一样。桥接把拨号交给自己的路由器，路由模式则由光猫分配地址。</p>
<p>要多地址的场景，通常需要光猫桥接加多拨，或者直接向运营商申请多个地址。前者成本低，后者稳定。</p>
<p>先问清上游给的是静态地址还是动态地址。动态地址做池子要额外处理，设备选型也跟着变。</p>

<h2>二、必备设备清单</h2>
<p>光猫或光端机由运营商提供，型号不可选，但要确认能不能改桥接。这一条决定后面所有配置。</p>
<p>路由器是核心，要求能刷第三方固件或多WAN，NAT性能至少千兆。便宜家用路由挂十几个地址会频繁重启。</p>
<p>交换机按端口数买，留两成余量。服务器可以用小型主机或工控机，功耗比塔式机低很多。</p>

<h2>三、配置顺序不能乱</h2>
<h3>桥接还是路由模式</h3>
<p>先改光猫为桥接，再在路由器上配置拨号。顺序反了会出现双重NAT，端口映射怎么设都不通。</p>
<p>改桥接前记下原参数，包括VLAN和拨号账号密码。改错后恢复出厂也找不回来，只能报障。</p>
<p>多WAN要把每条线的权重和故障切换配好。默认主备模式，主线路断了才切，避免流量乱走。</p>
<p>拨号账号和密码要单独备份。设备损坏后重新配置，没有这两项就要重新找运营商，恢复时间会拖到几天。</p>
<h2>四、交换机与布线</h2>
<p>弱电箱空间小，设备叠放容易过热。交换机选金属外壳无风扇的，静音也耐用。</p>
<p>网线用超五类以上，长度控制在九十米内。多地址场景建议按地址分组走不同交换机，排查时能整组断开。</p>
<p>标签别省。十几个口插满以后，没有标签的布线等于没有布线，排查一次要多花半天。</p>
<h2>五、供电与散热</h2>
<p>小型主机和路由器的总功耗不高，但弱电箱散热差，夏天容易降频。留出通风口，必要时加一个静音风扇。</p>
<p>UPS按总功耗选，撑十分钟足够完成安全关机。停电对硬盘和数据库的伤害比想象中大。</p>
<h2>六、上电后的连通性验证</h2>
<p>按顺序查：物理链路、拨号状态、出口地址、DNS解析、端口可达。哪一步断，问题就在那一层。</p>
<p>出口地址要用外部接口查，不要看路由器自己报的。双重NAT时，本地看到的地址往往不是真实出口。</p>
<p>最后跑一轮持续探活，观察二十四小时。掉线集中在某个时段，多半是上游拥塞或设备过热。</p>
<h3>检查记录怎么留</h3>
<p>把每一步的检查结果写进配置文档。换人接手时，文档比口头交接可靠得多，也能避免重复踩坑。</p>
<h2>常见问答</h2>
<h3>一定要用光猫桥接吗？</h3>
<p>答：不一定。单地址场景路由模式加端口映射也能用，多地址或需要固定出口时桥接更灵活，具体看运营商是否允许。</p>
<h3>家用路由器能带几个地址？</h3>
<p>答：普通家用型号带三到五个还行，再多NAT表和会话数会吃紧，建议换企业级设备或软路由。</p>
<h3>设备总功耗大概多少？</h3>
<p>答：光猫加路由加小型主机，常见三十到六十瓦，一个月电费几十元，具体看配置和当地电价。</p>
<h3>没有固定公网地址能搭吗？</h3>
<p>答：可以，但出口会变。需要固定出口时用动态域名加定时同步，或者向运营商申请静态地址。</p>
